# 古诗里的位置：有序数对与平移

从原有《古诗数对与平移》源码迁入的首个独立讲题示例。统一运行方式见 [视频模块说明](../../../video-lessons/README.md)。

## 题目

《赠汪伦》按 `storyboard.json` 排列在 9 列、6 行的方格里，列号从左往右，行号从下往上。

1. “舟”位于第 5 列、第 4 行，数对是 **（5，4）**。
2. **（7，2）** 对应 **“千”**。
3. 整首诗向左平移 1 格，“赠”由 **（4，6）** 移到 **（3，6）**。

网格、标号固定，标题、作者、诗句和标点一起移动。画面由 Pillow + NumPy 逐帧绘制，直接送入 FFmpeg；字幕绘制进画面，同时可导出 SRT。

## 文件

- `render_lesson.py`：保留原例的逐帧绘图逻辑，新增字体查找、音轨/时间轴选项和短片测试参数。
- `generate_tts.py`：保留逐句 TTS、PCM 拼接和采样级时间轴，新增离线缓存模式及独立输出目录。
- `storyboard.json`：题目网格、14 个分镜、26 句旁白和答案。
- `timeline.json`、`subtitles.srt`：原版配音的参考时间轴与字幕。新配音的版本写入 `output/`。
- `assets/README.md`、`assets/OFL.txt`：字体获取及第三方许可说明。
- `PROVENANCE.md`：迁入来源和未随 Git 发布的素材说明。

参考成品为 1080p、24 fps、3036 帧（126.5 秒）。这些是原版数据，不保证新 TTS 生成结果恰好同长。
