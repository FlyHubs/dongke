# 字体与题目图片

原示例使用 Noto Sans CJK SC Regular / Bold。字体二进制不提交 Git；可从 [Noto CJK 官方项目](https://github.com/notofonts/noto-cjk/tree/main/Sans) 获取，将 `NotoSansCJKsc-Regular.otf` 和 `NotoSansCJKsc-Bold.otf` 放在本目录，或给渲染器传入 `--font-dir`。

Noto Sans CJK 字体采用 SIL Open Font License 1.1，原包附带的许可全文保留在 `OFL.txt`。字体版权与许可不变；系统安装的字体以其分发包许可为准。

本示例不需要题目截图。原始 `source_problem.jpg` 的公开再分发授权未确认，因此不包含在此仓库。
